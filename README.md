# realchrisolin.workspaces

Omarchy bar workspace strip, cloned from `omarchy.workspaces`.

Plugin id: `realchrisolin.workspaces`  
Live path: `~/.config/omarchy/plugins/realchrisolin.workspaces`

Laptop panels use numeric workspaces 1–10. Other monitors (Miracast Extend,
HDMI, …) use named slots `ext-1`…`ext-10`.
